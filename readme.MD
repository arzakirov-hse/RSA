
# Реализация криптосистемы RSA

Данный проект представляет собой учебную реализацию асимметричной криптосистемы RSA на языке Python.  
Программа разработана в рамках лабораторной работы по дисциплине криптография.

---

## Описание проекта

В работе реализованы:

- генерация ключевой пары RSA;
- возможность ручного ввода параметров (p, q, e);
- поблочное шифрование данных;
- расшифрование данных;
- работа с файлами (ввод/вывод);
- отдельная реализация атак на RSA (для малых параметров).

Реализация выполнена **без использования готовых криптографических библиотек**, что позволяет детально изучить внутреннюю работу алгоритма.

## Функциональные возможности

Программа `RSA.py` поддерживает:

- генерацию ключей заданной битности;
- ввод ключей вручную;
- автоматический расчёт размера блока;
- шифрование файлов;
- расшифрование файлов;
- работу с большими числами (Big Integer).

## Особенности реализации

### Поблочное шифрование

Данные разбиваются на блоки. Размер блока рассчитывается автоматически:

```
block_size = (bit_length(n) / 8) - 1
```

Это гарантирует выполнение условия:
```
m < n
```

## Реализованные атаки

В файле `rsa_attacks.py` реализованы:

### 1. Атака Ферма
Используется для факторизации числа n, если p и q близки друг к другу.

### 2. Атака на малую экспоненту (Low Exponent Attack)
Работает при малых значениях e (например, e = 3).
